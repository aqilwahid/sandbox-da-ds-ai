# Browser Hands-On Sandbox (DA, DS, & AI)

Platform pembelajaran interaktif berbasis browser untuk Data Analytics, Data Science, dan Artificial Intelligence. Dilengkapi dengan in-browser code editor (SQL & Python), sistem evaluasi otomatis, dan materi pembelajaran modular.

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Code Editor**: CodeMirror 6 (SQL & Python support)
- **Local Database / Storage**: Dexie (IndexedDB)
- **PWA**: vite-plugin-pwa

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Jalankan Development Server
```bash
npm run dev
```

### 3. Build Production
```bash
npm run build
```
